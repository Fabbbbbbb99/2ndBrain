# 🛠️ Learned Corrections & User Preferences

Stores durable rules, developer style preferences, and corrected bug patterns extracted from live conversations and user prompts.

### Format
Notes in this folder are auto-generated by `memory_distiller.py` and filtered via `Laya` ($P > 0.7$).
When a new prompt is received, relevant notes are automatically recalled and injected into LLM context.
